# 縦型動画メーカー

読み上げ音声(CapCut・TikTok などで作ったナレーション)から、

1. **無音カット**(初期設定は「即カット」: 無音が来たらすぐ切る)
2. **ローカル文字起こし**(whisper.cpp、外部APIなし)
3. **シーンとテロップの自動分割**
4. **画像・動画・BGM の当てはめ**

を行い、**1080×1920(9:16)の MP4** を書き出す、自分の Mac だけで使う編集ツールです。
ブラウザで `http://127.0.0.1:5178/` を開いて操作します。

## セットアップ(初回だけ)

必要なもの: macOS(Apple Silicon / Intel どちらも可)、[Homebrew](https://brew.sh)

```bash
cd このフォルダ
./setup.sh
```

`setup.sh` は次を行います。

- `brew install node ffmpeg whisper-cpp`(入っていないものだけ)
- `npm install`(依存は Claude API の公式SDK `@anthropic-ai/sdk` 0.129.0 と、開発用の TypeScript・型定義。バージョンは package.json で固定)
- `npm run build`

## Mac アプリ版(.dmg)

ターミナルを使わずに使いたい場合は、GitHub の **Releases →「Mac アプリ(最新)」** から .dmg をダウンロードします
(Apple シリコン=M1 以降は `TateDougaMaker-arm64.dmg`、Intel は `TateDougaMaker-x64.dmg`)。
プッシュするたびに GitHub Actions が自動で作り直します(Actions の実行結果からもダウンロード可)。

1. .dmg を開き、アプリを「Applications」へドラッグ
2. 初回は「開発元を確認できない」と出るので、システム設定 → プライバシーとセキュリティ →「このまま開く」
3. 起動するとブラウザで画面が開きます。Dock のアイコンで開き直し、右クリック →「終了」で終了

Node.js・FFmpeg・whisper.cpp を同梱しているので、Homebrew などの準備は要りません。
データ(`~/TateDougaMaker`)はターミナル版と共通です。同時に2つは起動できず、片方が動いているときはその画面を開きます。
画面右上に「アプリ版 日付 コミット」または「開発版」と表示されます。

## 起動

`start.command` をダブルクリック(または `./start.command`)。ブラウザが自動で開きます。
終了はターミナルで `Ctrl+C`。

手動で起動する場合: `npm start`(ビルドして起動)/ `npm run serve`(ビルド済みを起動)

ブラウザは **Chrome か Safari** を推奨します(H.264 動画のプレビューに必要)。

## 文字起こしモデル(初回だけダウンロード)

「2 自動編集」の画面で、マシンに合わせた推奨モデルが選ばれます。「モデルをダウンロード」を押すと進捗が表示され、失敗しても再試行できます(途中から再開します)。

| モデル | 容量 | 用途 |
| --- | --- | --- |
| small (q5_1) | 約190MB | 速度重視 |
| medium (q5_0) | 約539MB | 中間 |
| large-v3-turbo (q5_0) | 約574MB | 精度重視(Apple Silicon の推奨) |
| large-v3-turbo | 約1.6GB | 非量子化 |

- 取得元: `https://huggingface.co/ggerganov/whisper.cpp`(英語専用モデルは使いません)
- 保存先: `~/TateDougaMaker/models/`(`TDM_MODELS_DIR` で変更可)
- 手動で置く場合は、上記のファイル(例: `ggml-large-v3-turbo-q5_0.bin`)を保存先に入れてください。
- モデルのダウンロード以外で、音声や動画を外部に送ることはありません。

## 文字起こしを Gemini API で行う(任意・高精度)

ローカルの whisper.cpp の聞き取りが物足りない場合は、Google の Gemini API に切り替えられます。

1. https://aistudio.google.com/apikey で APIキーを発行
2. 「2 自動編集」→「文字起こし」で **Gemini API(クラウド)** を選び、APIキーを入れて「保存」
   - キーは `~/TateDougaMaker/secrets.json`(本人のみ読み書き可)に保存し、project.json やログには入れません。環境変数 `GEMINI_API_KEY` でも指定できます
3. モデルは初期値「自動(最新の flash)」のままで OK(実行時に Google のモデル一覧から最新の安定版 flash を選びます)。より高精度にしたい場合は「モデル一覧を取得」から pro 系を選ぶ
4. 「このプロジェクトの音声を Google Gemini API に送信することに同意する」にチェックして「自動編集を実行」

仕組み: Gemini は語ごとの時刻を返さないため、音声を無音で区切った「音声片」(フレーズ単位)ごとに送り、
**文字は Gemini、表示のタイミングは音声片の区切り(音量解析)** で決めます。音声片の中の語の位置は文字量からの推定です。
早口で話し続ける所では、この推定だとテロップが声より遅れる(早まる)ことがあるため、**whisper.cpp のモデルが1つでも入っていれば、
ローカルの whisper で声のタイミングを調べ、Gemini の文字をその時刻に合わせます**(この処理の音声は外部に送信しません)。
モデルが無い場合は「文字起こし」の Gemini の欄にダウンロードボタンが出ます。既存のプロジェクトは「自動編集を実行」をもう一度押すと
(Gemini の結果は前回分を再利用するので追加料金なし)時刻が合わせ直されます。
送信するのはナレーション音声(16kHz モノラル)と、台本から抜き出した語句ヒントだけです。利用料は Google の料金体系に従います。

## Claude で素材を自動で割り当てる(任意)

取り込んだ画像・動画の中身を Claude(`claude-opus-5-5`)が見て、各カットで話している内容に合う素材と、動画のどの場面から使うかを選びます。

1. 「2 自動編集」の **1カットの長さ** で「1〜2秒(テンポ重視)」などを選び、自動編集(または「テロップ・シーンを作り直す」)
2. **Claude で素材を割り当てる** に Claude の APIキー(https://platform.claude.com の API Keys)を入れて保存
   - `~/TateDougaMaker/secrets.json` または環境変数 `ANTHROPIC_API_KEY`。project.json には入りません
3. 使う素材を選び、送信内容への同意にチェックして実行
   - 送るのは、素材のフレーム画像(動画は場面ごとに1枚・長辺384px。場面が多いときは4場面ずつ並べた画像)とカットごとのテロップ・台本だけです
4. 結果は各シーンに反映され、理由が表示されます(元に戻す で一括取り消し可)

**素材の指定(参考)**: 台本の行ごとに使う素材が決まっている場合は、「素材の指定(参考)をもとに割り当てる」にチェックし、
スプレッドシートで「台本」と「素材」の2列をコピーして貼り付けます(セル内の改行もそのままで可)。
各カットを台本の行に対応づけ(読み取った行と対応したカット数が表に出ます)、「サナ」「商品アップ」「飲んでいる」などの指定に合う場面を優先して選びます。
チェックしなければ全部おまかせです。

**カットごとに間を足す**: 「3 確認して修正」でカットを選び、右の「このカットの後の間」で +0.2〜1秒(スライダーで 0〜2秒)を選ぶと、
無音で詰めた後でもそのカットの終わりだけ間(無音)が入ります。次のカットとテロップはその分後ろへずれ、背景の映像はそのまま流れます。
自動編集をやり直しても、終わりの位置がほぼ同じカットには引き継がれます。

**映像の上に画像を重ねる(商品画像・成分の説明など)**: 「3 確認して修正」で、左の素材一覧の画像をプレビュー画面へドラッグすると、
そのカットの映像の上に重なります(画面に収まる大きさで、落とした位置に置きます)。プレビュー上でドラッグすると移動、
ホイール(2本指スクロール)で大きさを変えられます。外すときは右の「重ねる画像を外す」。動画をプレビューへ落とすと、そのカットの背景になります。

**台本の表どおりのカット割り**: 「2 自動編集」の「1カットの長さ」で「台本の表どおり」を選び、同じ表を貼り付けると、
表の1行を1カットにします(行の切れ目は文字起こしの中から探し、テロップも行の切れ目で区切ります。長い行も分けません)。
話していない行は前の行と同じカットになります。素材の割り当て欄の表から「カット割りもこの表に合わせる」でも切り替えられます。

動画素材は、映像の切り替わりを検出して「場面」に分け(長く続く場面は数秒ずつに分割)、場面ごとに Claude に見せます。
1本の中にいろいろな映像が入っている素材でも、それぞれの場面を別々に選べます。
Claude はカットごとに候補を3つまで挙げ、アプリ側で **同じ場面を近いカット(最大8カット以内)で使わない**・**同じ長い場面の一部を続けて使わない** ように選び直します。
最初と最後のように離れたカットでは、同じ場面が使われることがあります。
安全判定で断られた場合はサーバー側で別モデルに切り替える設定(`fallbacks: "default"`)を有効にしています。
利用料は Claude API の従量課金です(目安: 素材20個・30カットで入力3〜4万トークン程度)。

## テンポと動き(「2 自動編集」)

**話す速さの緩急**: 一律の速さではなく、カットごとに速い所・遅い所を作ります(声の高さは変わりません)。
- 台本から(おすすめ): 数字・商品名・「！」・最後の呼びかけなど大事なカットをゆっくり、つなぎ(〜けど・〜て など)や長い説明を速く
- 波: 約8秒で速い→遅いを繰り返す / ときどき速く: 3カットに1回ぐっと速く
- 「いちばん速いカット」「いちばん遅いカット」の速さを選べます(目安は最大 1.3〜1.4 倍。早回しの研究では 1.25〜1.5 倍程度までは理解がほとんど落ちないとされます)
- 隣のカットの差は 0.25 倍までにし、急に変わりすぎないようにします。「3 確認して修正」で手で変えたカットはそのまま残ります
- 「カットの後の間」: 大事なカット(ゆっくりのカット)や文の終わりの後に間を置き、話の途中は詰めます(いちばん長い間を選べます。0 で使わない)
- 緩急の波のグラフ: 点を上下にドラッグするとそのカットの速さ、下の棒をドラッグするとカットの後の間を変えられます(手で変えた所は白で表示し、自動の緩急で上書きしません)

**カットの声**: 「3 確認して修正」でカットを選び、「このカットの声」で大きさ(-12〜+9dB)・高さ(-4〜+4 半音)を変えられます(強調・張り上げる などのボタンあり)。速さは変わりません

- **1カットの長さ**: 「テロップごと(おすすめ・初期値)」は、テロップ1つにつき1カットで背景を切り替え、0.6秒未満の短いカットは隣とまとめます(細切れが続くと目が疲れるため)。ほかに 1〜2秒 / 2〜3秒 / 2〜5秒 の均等なカット割りも選べます。
- **テロップの長さ**: 「短く区切る(1行・11文字まで・初期値)」にすると、「色黒女子は / 全員これ使え」「白玉点滴とか / 美容医療に手出す前に」のように話の区切りごとにテロップを分けます(whisper の細切れの認識結果も、辞書で語にまとめ直してから区切ります)。
- **カット内の動き**: 背景にズームイン・ズームアウト・上下左右のパン・パンチイン・インパクト・揺れを付けます。「全カットにおまかせで動きを付ける」で、強調のカットには強め、それ以外はゆっくりした動きを連続しないように割り振ります。Claude で素材を割り当てたときにも自動で付けられます。動きの式はプレビューと書き出しで同じものを使い、端に黒い余白が出ない範囲で動かします。

## 使い方

画面上部の 4 つの手順に沿って進めます。

1. **素材を取り込む** — 左の素材置き場にナレーション音声(MP3/WAV/M4A)や動画(MP4/MOV)、背景用の画像・動画、BGM、フォント(TTF/OTF)をドロップ。右側でナレーションに使う素材(音声トラックが複数あればトラックも)を選びます。台本は任意で、貼ると固有名詞・数字の認識ヒントと表記確認に使います(台本の文章を字幕に勝手に入れることはしません)。
   - BGM が混ざった音声は無音カット・文字起こしの精度が落ちます。できればナレーションだけの音声を使ってください。
2. **自動編集** — 無音カットのプリセット(**即カット** / テンポよく / 自然 / カスタム)を選び、「自動編集を実行」。文字起こし → カット → シーン・テロップが作られます。
   - タイムラインを「元音声(カット確認)」にすると、削る場所(赤)を確認でき、無音候補をクリックすると「この間は残す」を切り替えられます。カット前/後の聞き比べもできます。
   - 小声でも文字起こしで言葉があると判断した箇所は削りません(黄色)。
3. **確認して修正** — 左のシーン一覧に素材をドラッグして背景を割り当て(または素材にチェック → 「選択順にシーンへ仮配置」)。テロップは文章・改行・表示時間・分割/結合、個別の位置・色・フォントを変更できます。プレビューのテロップはドラッグで移動できます。BGM・音量もここで設定します。
4. **動画を書き出す** — 書き出し前チェック(フォントの読み込み・フォントに無い文字など)を確認して「動画を書き出す」。書き出しは開始時点の内容で行われ、その間も編集を続けられます。任意で編集済みナレーションの WAV と字幕 SRT も保存できます。

ショートカット: スペース=再生/停止、←→=0.1秒移動(Shift で1秒)、⌘Z / ⇧⌘Z=元に戻す/やり直す

## 背景の位置・場面を手で直す

「3 確認して修正」でシーンを選ぶと:
- **プレビューの映像をドラッグ** すると、見せる位置(切り取る場所)を動かせます。**ホイール(トラックパッドのピンチ)** で拡大率を変えられます
- Claude で割り当てたカットは **別の候補にする** で、Claude が挙げたほかの候補に順に切り替えられます(押し続けると一巡して元に戻ります)
- 動画の素材は **このカットで使う区間** の帯(動画全体のサムネイル)で、見せる区間の枠をドラッグ・クリックして選べます(プレビューも追従、0.1秒・1秒ずつの微調整も可)
- 動画の素材は **場面を一覧から選ぶ** で、動画を場面ごとに分けたサムネイルから使う場面を選べます。ほかのカットで使っている場面には「使用中 #番号」が付きます
- 素材そのものを変えるときは「素材」の欄で選ぶか、左の素材をシーンのカードへドラッグします

## 文字起こしの間違いを直す

「3 確認して修正」の **一覧** タブで、全テロップを並べて直接書き換えられます(文字をクリックするとその場所へ移動、▶ でその部分を再生)。
黄色の行は認識が怪しい所です。

同じ間違いが何か所もあるときは、上の **まとめて置き換え**(例: 白球 → 白玉)を使います。
「この直しを覚える」にチェックしておくと、カットの作り直しや次の文字起こしでも自動で直し、認識のヒント(Gemini・whisper)にも使います。
テロップを直しても音声は変わりません。

## CapCut のプロジェクトとして書き出す(iPhone でも続きを編集)

テロップの入れ方は「見た目そのまま(画像・初期値)」と「CapCut で編集できる文字」から選べます。
見た目そのままはプレビューと同じフォント・大きさ・位置・縁取りで入りますが、CapCut で文字は直せません。

「4 動画を書き出す」の **CapCut に書き出す** で、CapCut(デスクトップ版・国際版)の編集途中のプロジェクトを作ります。

1. **CapCut を終了**しておく(起動中は書き出せません。CapCut が終了時にプロジェクト一覧を書き直すため)
2. CapCut のプロジェクトが1つも無い場合は、CapCut で「新しいプロジェクト」を1つ作って閉じておく
   (そのプロジェクトを見本にして、お使いの CapCut の版の形式に合わせます)
3. 「CapCut に書き出す」を押し、CapCut を起動するとプロジェクト一覧に表示されます

入るもの: カット済みのナレーション(速さ・被せも反映した1本の音声)、背景素材(カットごとに区切り、ズーム・パン・揺れはキーフレーム)、
ワイプ、BGM(ループ・フェード)、テロップ(CapCut の文字として入るので、あとから文字・位置・フォントを直せます)。
テロップは CapCut の標準フォントになり、大きさ・縁取りは近い値です。見た目が違えばテロップをまとめて選んで調整してください。

**iPhone で続きを編集するには**: Mac の CapCut でこのプロジェクトを開き、クラウド(スペース)にアップロードすると、
同じアカウントの iPhone の CapCut から開けます(iPhone の CapCut にはファイルから直接プロジェクトを読み込む方法がありません)。

注意: CapCut のプロジェクト形式は公開されていないため、[capcut-cli](https://github.com/renezander030/capcut-cli)(MIT)と
[pyCapCut](https://github.com/GuanYixuan/pyCapCut) の調査結果に基づいています。CapCut 10 以降では外部で作ったプロジェクトを
「破損」として開かないという報告があります。剪映(中国版)6.0 以降はプロジェクトが暗号化されているため対象外です。
下書きの場所は既定で `~/Movies/CapCut/User Data/Projects/com.lveditor.draft`(CapCut の「設定 → 下書きの場所」で確認できます)。

## 素材ライブラリ(素材はプロジェクトごとにコピーしない)

- 取り込んだ音声・動画・画像は「素材ライブラリ」(`~/TateDougaMaker/library`)に1回だけ保存し、どのプロジェクトからも使えます(同じファイルを2回取り込んでも保存は1回)。左の素材一覧の下の「素材ライブラリ」から「＋」で使います
- 「ファイルを選ぶ(コピーしない)」「フォルダから(コピーしない)」「CapCut の素材から」は、元の場所のファイルをそのまま使います(容量は増えません。元のファイルを移動・削除すると使えなくなります)
- CapCut に書き出すときも、ライブラリの素材はコピーせずに参照します(CapCut の下書きとこのアプリで同じファイルを使う)
- 以前のプロジェクトにコピーしてある素材は、素材一覧の「素材ライブラリに移す」でライブラリに移せます(重複している分は削除)

## CapCut の声で台本を読み上げる

CapCut の読み上げの声は CapCut の中でしか作れない(外から使える公式の仕組みがない)ため、声を選ぶ所だけ CapCut で行います。

1. 「1 素材を取り込む」の「台本」に読み上げる文章を入れる(1行が1つの読み上げ。スプレッドシートの「台本 / 素材」の表をそのまま貼っても可。その場合は素材の指定(参考)にも使います)
2. CapCut を終了した状態で「読み上げ用のプロジェクトを作る」→ CapCut に「<名前> 読み上げ用」ができる
3. CapCut で開き、文字クリップを全部選んで(⌘A)「テキスト読み上げ」で声を選ぶ → CapCut を終了
4. 「読み上げた音声を読み込む」→ 行ごとの読み上げ音声を順につなげてナレーションにし、無音カット(つらつら・即カットなど)・テロップ(台本の文章)・カット割りを作る
5. あとはいつもどおり、素材の割り当て(Claude)・プレビュー・カットごとの間や速さの調整 → 動画または CapCut に書き出し

テロップの時刻は、行ごとの声のある所に文字量で配分した推定です(テロップの文章は台本どおり)。

## CapCut で作った音声・テロップから始める(素材の割り当てだけこのアプリで)

無音カット・テロップ・話す速さは CapCut で作り、素材の割り当て(Claude)だけこのアプリで行う使い方です。

1. CapCut でナレーションを編集(無音部分の削除・自動キャプションなど)し、**CapCut を終了**する(終了時に保存されます)
2. このアプリで新しいプロジェクトを作り、「1 素材を取り込む」の「CapCut で作った音声・テロップから始める」で、そのプロジェクトを選んで読み込む
   - 音声(全トラックを重ねたもの)を1本にしてナレーションに、CapCut のテロップをそのままテロップにします
   - 無音カット・文字起こし・速さ・間の調整はしません(CapCut 側で済んでいる前提)
3. 素材(動画・画像)を取り込み、「2 自動編集」でカット割り(テロップごと・台本の表どおりなど)と Claude の割り当て、「3 確認して修正」で手直し
4. 「4 動画を書き出す」の「CapCut に素材入りのプロジェクトを作る」で、元のプロジェクトを複製して素材(背景・ワイプの映像トラック)を入れた「<元の名前> 素材入り」を作ります。音声・テロップ・エフェクトは元のまま、元のプロジェクトは変更しません

CapCut の版によってはプロジェクトが暗号化されていて読み込めないことがあります(その場合は一覧に「読み取れませんでした」と出ます)。
読み込んだ後に CapCut で音声やテロップの位置を変えた場合は、「CapCut から読み込み直す」で合わせ直せます(割り当てた素材は同じ時間のカットに引き継ぎます)。

## 初期設定

| 項目 | 初期値 |
| --- | --- |
| 無音カット「つらつら(被せ)」 | 50ms以上の無音をカットし、さらに前後の発話へ計80ms食い込んでクロスフェードで重ねる(無音をなくして詰めたいとき。感度を+2〜+3にするとさらに詰まる) |
| 無音カット「即カット」 | 100ms以上の無音をカット。話し始めの前30ms・語尾の後40msだけ残す。冒頭・末尾の無音も削除 |
| 「テンポよく」 | 250ms以上 → 約100ms |
| 「自然」 | 350ms以上 → 約180ms |
| 接合点フェード | 4ms(音声の長さは変わりません) |
| 話す速さ | シーンごとに 0.5〜2.0倍(初期値 1.0倍)。声の高さは変えずに速さだけ変える(WSOLA)。テロップ・元動画と同期した映像も追従 |
| テロップ | 白・太字(Noto Sans JP Black)・黒縁6px・76px・最大幅880px・最大2行・中心(50%, 43%) |
| シーン / テロップの長さの目安 | 2〜5秒 / 0.8〜3秒 |
| 背景 | 画面いっぱい。動画が短いときは末尾静止。素材の元音声はミュート |
| 出力 | 1080×1920 / 30fps / H.264 / AAC 192kbps / MP4 |

無音カットの数値は調整の出発点で、見本動画から測定した値ではありません。

## 仕組み(概要)

- `src/shared/` … ブラウザとサーバーで共通の小さなモジュール
  - `timemap.ts` 元音声 → 編集後の**時間対応表**(`sourceStart/End`・`outputStart/End` を整数サンプルで保持)。字幕・シーン・映像の同期はすべてこれを通します
  - `silence.ts` 音量解析・無音候補・削る区間の決定(認識結果で小声を保護)
  - `segment.ts` 句読点・接続表現・発話の間・文字量を組み合わせたテロップ/シーン分割
  - `jatext.ts` 禁則処理つきの改行
  - `captionRender.ts` テロップ描画。**プレビューも書き出し用の透明PNGも同じ関数・同じフォントファイル**で描きます
  - `fit.ts` 背景・差し込み画像の配置計算(プレビューと FFmpeg で共通)
- `src/server/` … Node.js のローカルサーバー(依存ライブラリなし)。FFmpeg / whisper.cpp は引数配列で起動し、シェル文字列は使いません
- `src/web/` … 画面(フレームワークなしの TypeScript)

保存先 `~/TateDougaMaker/projects/<ID>/` の中身:

- `project.json` … 素材情報・文字起こし(原文)・カット設定・対応表・シーン・テロップ(表示文)・スタイル・BGM・書き出し設定(`schemaVersion` あり、原子的に保存、1つ前を `.bak` に保持)
- `assets/` 取り込んだ素材のコピー(元ファイルは変更しません) / `work/` 中間ファイル / `cache/` 認識結果のキャッシュ / `exports/` 完成品

セキュリティ: `127.0.0.1` でのみ待ち受け、Host / Origin / 独自ヘッダーを確認して外部サイトからの操作を拒否します。ファイル配信は素材IDで行い、任意のパスは読めません。

## 確認したこと・残る制約

開発環境(Linux のクラウド環境、ブラウザは Playwright の Chromium)で確認した内容です。**Mac 実機では未確認**です。

### 確認済み

- 単体テスト 23件(`npm test`): 保持区間→出力時刻の変換、削除境界をまたぐ字幕、冒頭・末尾の削除、1000区間での丸め誤差の非累積、無音カットで発話を1サンプルも削らないこと、「この間は残す」、小声の保護、無音区間の幻覚語の検出、テロップ/シーン分割、禁則改行、whisper.cpp の JSON 解析、書き出しのフレーム割り当て、SRT
- ブラウザ自動操作(`scripts/dev/e2e.mjs`)で、日本語・空白入りファイル名の取り込み → ナレーション設定 → **手入力テロップ+単色背景での最小書き出し** → テロップ・シーン自動生成 → 選択順の素材配置(回転メタデータ付き MOV・横長動画・画像)→ 差し込み画像・BGM・背景動画の音声・個別テロップのフォント/色/位置変更 → 書き出しのキャンセル → 再実行 → 再読み込みでの復元 → Undo
- 書き出し結果: 1080×1920 / 30fps / H.264 / AAC 48kHz、33.0秒の音声を即カットで25.14秒にし、動画は755フレーム(25.167秒、フレーム境界まで最小限の延長)
- 同期: 書き出した MP4 の音声で各文の立ち上がりを測ったところ、対応表の予測との差は**全区間で 3〜6ms**、末尾まで累積なし
- プレビューと書き出しの代表フレームを並べて比較し、背景のトリミング、差し込み画像、テロップの位置・改行・フォントが一致することを確認
- 外部 Origin / Host からの操作が 403 になること、壊れたファイルの取り込みで理由が表示されること

### 未確認・制約

- **実際の音声認識は未確認**: 開発環境のネットワーク制限でモデル(Hugging Face)を取得できず、whisper.cpp の実行経路はダミーモデルでしか動かしていません。E2E では既知の文章をトークンとして注入して、分割以降を確認しました。日本語の認識精度・トークン時刻の精度(目標: 発話開始とのずれ 100ms 以内)は、Mac で実音声を使って確認してください。トークン時刻は音量の立ち上がりで補正していますが、認識そのものの誤りは手動で直す前提です。
- テスト音声は本物の発話ではなく、音節状に揺れる合成音です。
- Mac 固有の動作(フォント一覧、Finder で開く、Homebrew の whisper.cpp、Metal での速度)、試聴での聞こえ方は未確認です。
- プレビューの動画再生はブラウザの対応形式に依存します(Chrome / Safari は H.264 可)。
- 素材は常にプロジェクト内へコピーします(参照方式・再リンクは未実装)。
- LLM による意味分割(任意機能)は未実装です。外部API は、利用者が有効にした場合の Gemini 文字起こしだけです。
- Claude による素材の割り当ては、GitHub のソースからビルドした SDK と模擬サーバーで送受信の形式を確認済みで、**実際の Claude API・選ばれる素材の妥当性は未確認**です。
- Gemini 連携は模擬サーバーで送受信の形式・APIキーの扱い・同意の確認までを確認済みで、**実際の Gemini API では未確認**です(開発環境から Google に接続できないため)。
- 素材の映像内容を理解して選ぶ機能はありません(「選択順に仮配置」は並べるだけです)。
