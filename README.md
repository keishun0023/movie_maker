# 縦型動画メーカー

読み上げ音声(CapCut・TikTok などで作ったナレーション)から、

1. **無音カット**(初期設定は「即カット」: 無音が来たらすぐ切る)
2. **ローカル文字起こし**(whisper.cpp、外部APIなし)
3. **シーンとテロップの自動分割**
4. **画像・動画・BGM の当てはめ**

を行い、**1080×1920(9:16)の MP4** を書き出す、自分の Mac だけで使う編集ツールです。
ブラウザで `http://127.0.0.1:5178/` を開いて操作します。

## セットアップ(初回だけ)

必要なもの: macOS(Apple Silicon / Intel どちらも可)、[Homebrew](https://brew.sh)

```bash
cd このフォルダ
./setup.sh
```

`setup.sh` は次を行います。

- `brew install node ffmpeg whisper-cpp`(入っていないものだけ)
- `npm ci`(依存は TypeScript と型定義だけで、`package-lock.json` で固定)
- `npm run build`

## 起動

`start.command` をダブルクリック(または `./start.command`)。ブラウザが自動で開きます。
終了はターミナルで `Ctrl+C`。

手動で起動する場合: `npm start`(ビルドして起動)/ `npm run serve`(ビルド済みを起動)

ブラウザは **Chrome か Safari** を推奨します(H.264 動画のプレビューに必要)。

## 文字起こしモデル(初回だけダウンロード)

「2 自動編集」の画面で、マシンに合わせた推奨モデルが選ばれます。「モデルをダウンロード」を押すと進捗が表示され、失敗しても再試行できます(途中から再開します)。

| モデル | 容量 | 用途 |
| --- | --- | --- |
| small (q5_1) | 約190MB | 速度重視 |
| medium (q5_0) | 約539MB | 中間 |
| large-v3-turbo (q5_0) | 約574MB | 精度重視(Apple Silicon の推奨) |
| large-v3-turbo | 約1.6GB | 非量子化 |

- 取得元: `https://huggingface.co/ggerganov/whisper.cpp`(英語専用モデルは使いません)
- 保存先: `~/TateDougaMaker/models/`(`TDM_MODELS_DIR` で変更可)
- 手動で置く場合は、上記のファイル(例: `ggml-large-v3-turbo-q5_0.bin`)を保存先に入れてください。
- モデルのダウンロード以外で、音声や動画を外部に送ることはありません。

## 文字起こしを Gemini API で行う(任意・高精度)

ローカルの whisper.cpp の聞き取りが物足りない場合は、Google の Gemini API に切り替えられます。

1. https://aistudio.google.com/apikey で APIキーを発行
2. 「2 自動編集」→「文字起こし」で **Gemini API(クラウド)** を選び、APIキーを入れて「保存」
   - キーは `~/TateDougaMaker/secrets.json`(本人のみ読み書き可)に保存し、project.json やログには入れません。環境変数 `GEMINI_API_KEY` でも指定できます
3. 「モデル一覧を取得」でモデルを選ぶ(初期値 `gemini-2.5-flash`。より高精度にしたい場合は pro 系)
4. 「このプロジェクトの音声を Google Gemini API に送信することに同意する」にチェックして「自動編集を実行」

仕組み: Gemini は語ごとの時刻を返さないため、音声を無音で区切った「音声片」(フレーズ単位)ごとに送り、
**文字は Gemini、表示のタイミングは音声片の区切り(音量解析)** で決めます。音声片の中の語の位置は文字量からの推定です。
送信するのはナレーション音声(16kHz モノラル)と、台本から抜き出した語句ヒントだけです。利用料は Google の料金体系に従います。

## 使い方

画面上部の 4 つの手順に沿って進めます。

1. **素材を取り込む** — 左の素材置き場にナレーション音声(MP3/WAV/M4A)や動画(MP4/MOV)、背景用の画像・動画、BGM、フォント(TTF/OTF)をドロップ。右側でナレーションに使う素材(音声トラックが複数あればトラックも)を選びます。台本は任意で、貼ると固有名詞・数字の認識ヒントと表記確認に使います(台本の文章を字幕に勝手に入れることはしません)。
   - BGM が混ざった音声は無音カット・文字起こしの精度が落ちます。できればナレーションだけの音声を使ってください。
2. **自動編集** — 無音カットのプリセット(**即カット** / テンポよく / 自然 / カスタム)を選び、「自動編集を実行」。文字起こし → カット → シーン・テロップが作られます。
   - タイムラインを「元音声(カット確認)」にすると、削る場所(赤)を確認でき、無音候補をクリックすると「この間は残す」を切り替えられます。カット前/後の聞き比べもできます。
   - 小声でも文字起こしで言葉があると判断した箇所は削りません(黄色)。
3. **確認して修正** — 左のシーン一覧に素材をドラッグして背景を割り当て(または素材にチェック → 「選択順にシーンへ仮配置」)。テロップは文章・改行・表示時間・分割/結合、個別の位置・色・フォントを変更できます。プレビューのテロップはドラッグで移動できます。BGM・音量もここで設定します。
4. **動画を書き出す** — 書き出し前チェック(フォントの読み込み・フォントに無い文字など)を確認して「動画を書き出す」。書き出しは開始時点の内容で行われ、その間も編集を続けられます。任意で編集済みナレーションの WAV と字幕 SRT も保存できます。

ショートカット: スペース=再生/停止、←→=0.1秒移動(Shift で1秒)、⌘Z / ⇧⌘Z=元に戻す/やり直す

## 初期設定

| 項目 | 初期値 |
| --- | --- |
| 無音カット「つらつら(被せ)」 | 50ms以上の無音をカットし、さらに前後の発話へ計80ms食い込んでクロスフェードで重ねる(無音をなくして詰めたいとき。感度を+2〜+3にするとさらに詰まる) |
| 無音カット「即カット」 | 100ms以上の無音をカット。話し始めの前30ms・語尾の後40msだけ残す。冒頭・末尾の無音も削除 |
| 「テンポよく」 | 250ms以上 → 約100ms |
| 「自然」 | 350ms以上 → 約180ms |
| 接合点フェード | 4ms(音声の長さは変わりません) |
| 話す速さ | シーンごとに 0.5〜2.0倍(初期値 1.0倍)。声の高さは変えずに速さだけ変える(WSOLA)。テロップ・元動画と同期した映像も追従 |
| テロップ | 白・太字(Noto Sans JP Black)・黒縁6px・76px・最大幅880px・最大2行・中心(50%, 43%) |
| シーン / テロップの長さの目安 | 2〜5秒 / 0.8〜3秒 |
| 背景 | 画面いっぱい。動画が短いときは末尾静止。素材の元音声はミュート |
| 出力 | 1080×1920 / 30fps / H.264 / AAC 192kbps / MP4 |

無音カットの数値は調整の出発点で、見本動画から測定した値ではありません。

## 仕組み(概要)

- `src/shared/` … ブラウザとサーバーで共通の小さなモジュール
  - `timemap.ts` 元音声 → 編集後の**時間対応表**(`sourceStart/End`・`outputStart/End` を整数サンプルで保持)。字幕・シーン・映像の同期はすべてこれを通します
  - `silence.ts` 音量解析・無音候補・削る区間の決定(認識結果で小声を保護)
  - `segment.ts` 句読点・接続表現・発話の間・文字量を組み合わせたテロップ/シーン分割
  - `jatext.ts` 禁則処理つきの改行
  - `captionRender.ts` テロップ描画。**プレビューも書き出し用の透明PNGも同じ関数・同じフォントファイル**で描きます
  - `fit.ts` 背景・差し込み画像の配置計算(プレビューと FFmpeg で共通)
- `src/server/` … Node.js のローカルサーバー(依存ライブラリなし)。FFmpeg / whisper.cpp は引数配列で起動し、シェル文字列は使いません
- `src/web/` … 画面(フレームワークなしの TypeScript)

保存先 `~/TateDougaMaker/projects/<ID>/` の中身:

- `project.json` … 素材情報・文字起こし(原文)・カット設定・対応表・シーン・テロップ(表示文)・スタイル・BGM・書き出し設定(`schemaVersion` あり、原子的に保存、1つ前を `.bak` に保持)
- `assets/` 取り込んだ素材のコピー(元ファイルは変更しません) / `work/` 中間ファイル / `cache/` 認識結果のキャッシュ / `exports/` 完成品

セキュリティ: `127.0.0.1` でのみ待ち受け、Host / Origin / 独自ヘッダーを確認して外部サイトからの操作を拒否します。ファイル配信は素材IDで行い、任意のパスは読めません。

## 開発

```bash
npm test                 # 単体テスト(時間対応表・無音カット・分割・改行・whisper出力の解析)
node scripts/dev/make-test-media.mjs /tmp/media     # テスト素材を作る
node scripts/dev/e2e.mjs /tmp/media /tmp/e2e 5199   # ブラウザ自動操作による確認(Playwright が必要)
```

## 確認したこと・残る制約

開発環境(Linux のクラウド環境、ブラウザは Playwright の Chromium)で確認した内容です。**Mac 実機では未確認**です。

### 確認済み

- 単体テスト 23件(`npm test`): 保持区間→出力時刻の変換、削除境界をまたぐ字幕、冒頭・末尾の削除、1000区間での丸め誤差の非累積、無音カットで発話を1サンプルも削らないこと、「この間は残す」、小声の保護、無音区間の幻覚語の検出、テロップ/シーン分割、禁則改行、whisper.cpp の JSON 解析、書き出しのフレーム割り当て、SRT
- ブラウザ自動操作(`scripts/dev/e2e.mjs`)で、日本語・空白入りファイル名の取り込み → ナレーション設定 → **手入力テロップ+単色背景での最小書き出し** → テロップ・シーン自動生成 → 選択順の素材配置(回転メタデータ付き MOV・横長動画・画像)→ 差し込み画像・BGM・背景動画の音声・個別テロップのフォント/色/位置変更 → 書き出しのキャンセル → 再実行 → 再読み込みでの復元 → Undo
- 書き出し結果: 1080×1920 / 30fps / H.264 / AAC 48kHz、33.0秒の音声を即カットで25.14秒にし、動画は755フレーム(25.167秒、フレーム境界まで最小限の延長)
- 同期: 書き出した MP4 の音声で各文の立ち上がりを測ったところ、対応表の予測との差は**全区間で 3〜6ms**、末尾まで累積なし
- プレビューと書き出しの代表フレームを並べて比較し、背景のトリミング、差し込み画像、テロップの位置・改行・フォントが一致することを確認
- 外部 Origin / Host からの操作が 403 になること、壊れたファイルの取り込みで理由が表示されること

### 未確認・制約

- **実際の音声認識は未確認**: 開発環境のネットワーク制限でモデル(Hugging Face)を取得できず、whisper.cpp の実行経路はダミーモデルでしか動かしていません。E2E では既知の文章をトークンとして注入して、分割以降を確認しました。日本語の認識精度・トークン時刻の精度(目標: 発話開始とのずれ 100ms 以内)は、Mac で実音声を使って確認してください。トークン時刻は音量の立ち上がりで補正していますが、認識そのものの誤りは手動で直す前提です。
- テスト音声は本物の発話ではなく、音節状に揺れる合成音です。
- Mac 固有の動作(フォント一覧、Finder で開く、Homebrew の whisper.cpp、Metal での速度)、試聴での聞こえ方は未確認です。
- プレビューの動画再生はブラウザの対応形式に依存します(Chrome / Safari は H.264 可)。
- 素材は常にプロジェクト内へコピーします(参照方式・再リンクは未実装)。
- LLM による意味分割(任意機能)は未実装です。外部API は、利用者が有効にした場合の Gemini 文字起こしだけです。
- Gemini 連携は模擬サーバーで送受信の形式・APIキーの扱い・同意の確認までを確認済みで、**実際の Gemini API では未確認**です(開発環境から Google に接続できないため)。
- 素材の映像内容を理解して選ぶ機能はありません(「選択順に仮配置」は並べるだけです)。
