# 写真投稿をチャットで作る

アプリの写真投稿メーカー(`/carousel`)と同じ見た目の 1080×1920 の PNG を、チャットの中で作って渡す手順。
中身(お題・左右の言葉・本文)は、アプリなら Claude API が書く部分を、ここでは自分で書く。

## 1. 中身を書く

`src/server/carousel/write.ts` の `systemPrompt` にある書き方と禁止事項に従う。要点:

- 1枚目は表紙(`kicker` 20文字以内 + `title` 16文字以内)。2枚目以降は1ページ1お題で、左がダメな例・右が良い例
- お題 10文字以内、左右の言葉 8文字以内、補足 16文字以内。話し言葉で短く。問いかけのページを1つ入れてもよい
- けなす対象は習慣・行動・持ち物・やり方。生まれつきの顔立ち・体型・肌の色・年齢をばかにしない
- 医学的な効果を言い切らない。実在の人物・商品名は出さない
- 本文は1〜3行で、最後はコメントしたくなる問いかけ。ハッシュタグは3〜6個

枚数の指定がなければ、比較ページは5枚にする。左右の見出しは、利用者が「ドブス/爆美女」のような言葉を使っていれば `"heads": "words"`、そうでなければ `"marks"`(✖/〇)。

## 2. 画像

- 使ってよいのは、利用者がチャットに添付した画像と、無料で商用利用できる素材サイト(Pexels・Pixabay)の画像だけ。参考として貼られた他人の投稿の画像や、ウェブで拾った画像は使わない
- 添付画像はセッションの images フォルダに保存されている(メッセージの `[Image: source: ...]` のパス)。どの画像をどの枠に入れるか分からなければ聞く
- 画像がない枠は点線の枠になる。下書きとしてはそのまま出してよく、あとで画像を足して作り直す
- 素材サイトから取るには、その環境のネットワークで `api.pexels.com` `images.pexels.com`(または `pixabay.com` `cdn.pixabay.com`)が許可されていて、`PEXELS_API_KEY` / `PIXABAY_API_KEY` がある必要がある。なければアプリ側(Mac)で取るよう案内する

## 3. 描いて渡す

1. 指定の JSON をスクラッチパッドに書く(形は `scripts/carousel-render.mjs` の先頭のコメント。画像は JSON からの相対パスか絶対パス)
2. `npm run build`(未ビルドのときだけ)のあと、`node scripts/carousel-render.mjs 指定.json 出力フォルダ`
   - Playwright と Chromium が必要(クラウドの環境には入っている)
3. 出力された PNG を SendUserFile で渡す(全ページ。多ければ代表の数枚を `render`、残りは ZIP を `attach`)
4. 本文とハッシュタグは、そのまま貼れるように返信にも書く
5. 文字の修正を頼まれたら JSON を直して、もう一度描く
