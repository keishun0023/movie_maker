# 写真投稿をチャットで作る

アプリの写真投稿メーカー(`/carousel`)と同じ見た目の 1080×1920 の PNG を、チャットの中で作って渡す手順。
中身(お題・左右の言葉・本文)は、アプリなら Claude API が書く部分を、ここでは自分で書く。

## 1. 中身を書く

`src/server/carousel/write.ts` の `systemPrompt` にある書き方と禁止事項に従う。要点:

- 1枚目は表紙(`kicker` 20文字以内 + `title` 16文字以内)。2枚目以降は1ページ1お題で、左がダメな例・右が良い例
- お題 10文字以内、左右の言葉 8文字以内、補足 16文字以内。話し言葉で短く。問いかけのページを1つ入れてもよい
- けなす対象は習慣・行動・持ち物・やり方。生まれつきの顔立ち・体型・肌の色・年齢をばかにしない
- 医学的な効果を言い切らない。実在の人物・商品名は出さない
- 本文は1〜3行で、最後はコメントしたくなる問いかけ。ハッシュタグは3〜6個

枚数の指定がなければ、比較ページは5枚にする。左右の見出しは、利用者が「ドブス/爆美女」のような言葉を使っていれば `"heads": "words"`、そうでなければ `"marks"`(✖/〇)。

## 2. 画像

- 使ってよいのは、利用者がチャットに添付した画像と、無料で商用利用できる素材サイト(Pexels・Pixabay)の画像だけ。参考として貼られた他人の投稿の画像や、ウェブで拾った画像は使わない
- 添付画像はセッションの images フォルダに保存されている(メッセージの `[Image: source: ...]` のパス)。どの画像をどの枠に入れるか分からなければ聞く
- 画像がない枠は点線の枠になる。下書きとしてはそのまま出してよく、あとで画像を足して作り直す
- 素材サイトから取るには、枠に `image` の代わりに `"query": "英語の検索語", "kind": "photo" | "illustration"` を書き、環境変数 `PIXABAY_API_KEY`(または `PEXELS_API_KEY`)を付けてスクリプトを実行する。スクリプトがアプリと同じ処理で探して入れる(同じ画像は使い回さない)
  - その環境のネットワークで `pixabay.com` `cdn.pixabay.com`(Pexels なら `api.pexels.com` `images.pexels.com`)が許可されている必要がある。「素材サイトに接続できませんでした」と出たら、環境の Network access で許可するよう案内する(Node の fetch がプロキシを通らないときは `NODE_USE_ENV_PROXY=1` を付ける)
  - キーはリポジトリに書かない(スクラッチパッドの env ファイルか環境の設定に置く)
  - 合わない画像が入ったら、検索語を変えるか、その枠だけ利用者の画像にして描き直す

## 3. 描いて渡す

1. 指定の JSON をスクラッチパッドに書く(形は `scripts/carousel-render.mjs` の先頭のコメント。画像は JSON からの相対パスか絶対パス)
2. `npm run build`(未ビルドのときだけ)のあと、`node scripts/carousel-render.mjs 指定.json 出力フォルダ`
   - Playwright と Chromium が必要(クラウドの環境には入っている)
3. 出力された PNG を SendUserFile で渡す(全ページ。多ければ代表の数枚を `render`、残りは ZIP を `attach`)
4. 本文とハッシュタグは、そのまま貼れるように返信にも書く
5. 文字の修正を頼まれたら JSON を直して、もう一度描く

## 4. 企画管理のスプレッドシートから作る

「企画を作って」「作成するを作って」のように頼まれたら、Google スプレッドシート「写真投稿 企画管理」を使う(リンクがなければ Drive で `title contains '写真投稿 企画管理'` を検索)。タブ:

- `企画一覧`: 企画ID / ステータス / テーマ / フォーマット / 画像の方針 / 比較ページ数 / 追加の指示 / 投稿予定日 / 表紙の見出し / 本文 / ハッシュタグ / 出力ファイル / メモ
- `ページ`: 企画ID / ページ / 種類(表紙・比較) / ラベル・上の一言 / お題・見出し / お題の下の一言 / 左の言葉 / 左の補足 / 左の画像 / 右の言葉 / 右の補足 / 右の画像
- `フォーマット`: 名前 / 左右の見出し(記号・文字) / 左の言葉 / 右の言葉 / 背景 / 比較ページ数 / 下のキャラクター(左・右) / 書き方の指示
- `画像の方針`: 名前 / 取り方(素材サイト・手持ち・なし) / 種類(写真・イラスト) / 検索語に足す言葉 / 説明

手順:

1. `企画一覧` を読み、ステータスが「作成する」の行と「修正する」の行を対象にする。どれを作るか対象が多ければ確認する
2. 「作成する」: 行のフォーマット・画像の方針を各タブから引き、書き方の指示と追加の指示に従って中身を書く(枚数は行の比較ページ数、空ならフォーマットの枚数)。`ページ` タブにその企画IDの行を書く(既にあれば置き換える)。画像の列には、素材サイトなら英語の検索語(方針の「検索語に足す言葉」を足す)、手持ちなら「貼った画像1」のような名前を書く
3. 「修正する」: 中身は書き直さず、`ページ` タブの行をそのまま使う
4. `ページ` の行から指定 JSON を作って描く(背景: ラベンダー=lavender、ピンクの水面=pink-water、ミント=mint、クリーム=cream。見出し: 記号=marks、文字=words)。画像の列が検索語なら `query`、貼った画像ならそのファイル
5. PNG と ZIP を渡し、`企画一覧` の 表紙の見出し・本文・ハッシュタグ・出力ファイルを書き、ステータスを「作成済み」にする
6. シートへの書き込みは google-workspace スキルの手順に従う(書いたあと読み直して確かめる)
